# Vexo — Discord Bot

**Creator:** Aarav Singh  
**Based on:** Red-DiscordBot (GPL v3) with custom Termux and generic Python server enhancements.

Yeh repository ek custom Vexo bot hai jo Termux aur generic Linux/Python servers dono pe chalane ke liye optimized hai.

## Custom Features

- Modern slash commands: `/combo dynk`, `/combo carl`, `/combo falcon`, `/combo xieron`
- Improved AntiNuke embeds and slash command support
- Better theme styling for embeds, alerts, and info messages
- Termux install script plus generic Linux host instructions

## Quick Start

Setup ke liye `START.md` file padhein.

## Features

- Moderation (ban, kick, mute, warn)
